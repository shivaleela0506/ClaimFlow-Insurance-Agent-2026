PROJECT TITLE:
ClaimFlow - Insurance Claims Processing Agent

PROJECT DESCRIPTION:
ClaimFlow is an AI-based Insurance Claims Processing Agent developed in Python. The system helps users register insurance claims, check claim status, estimate claim settlement amounts, verify required documents, and access insurance-related information.

OBJECTIVES:
1. Automate insurance claim registration.
2. Assist users in tracking claim status.
3. Estimate insurance settlements.
4. Verify claim documents.
5. Provide insurance FAQs.

FEATURES:
- New Claim Registration
- Claim Status Tracking
- Claim Amount Estimator
- Document Verification
- Insurance FAQ Assistant
- View All Registered Claims

TECHNOLOGY USED:
- Python
- Visual Studio Code

HOW TO RUN:
1. Open terminal.
2. Navigate to project folder.
3. Run: python agent.py
